# 核心游戏设计

## 1. 游戏定位

横屏 3D 即时动作 RPG，单机离线。玩家操控圣斗士探索区域、接取剧情任务、即时战斗、成长并收集圣衣。仅开发 Android 手机端，不安排 Windows 电脑版。

## 2. 战斗系统（非回合制）

- 实时移动与镜头跟随。
- 普通攻击、技能快捷键、连招衔接。
- 闪避、格挡、目标锁定、受击硬直、击飞与击退。
- 暴击、霸体、小宇宙能量与爆发状态。
- Boss 有可识别的攻击前摇、范围提示、阶段变化和可躲避招式。
- 技能连携示例：天马流星拳衔接天马彗星拳。
- 战斗逻辑必须由玩家实时操作驱动，不使用回合制行动队列。

## 3. Android 横屏 HUD

- 左上：角色头像、等级、生命、小宇宙能量。
- 左上信息下方：当前任务、目标与进度。
- 任务区域下方：NPC 对话与任务提示；普通任务使用紧凑屏内对话框。
- 右上：小地图、玩家位置、任务与目标标记。
- 小地图左侧：离线商城入口。
- 左下：虚拟摇杆。
- 中下：技能快捷键与冷却状态。
- 右下：普通攻击键。
- 辅助操作：闪避、锁定目标、小宇宙爆发；布局可调整、缩放。

支持蓝牙手柄、自动拾取、自动寻路（仅导航，不代替战斗）、镜头距离/灵敏度、画质、特效和震动设置。

## 4. 职业

1. 天马座
2. 天龙座
3. 白鸟座
4. 仙女座
5. 凤凰座
6. 海龙
7. 天猛
8. 天琴
9. 海燕

每个职业规划独立模型、技能、动作、装备成长、专属剧情和神圣衣形态。天猛、天琴、海燕的具体人物背景与设定需在内容制作前确认，不擅自认定其原作身份。

## 5. 圣衣与装备

规划青铜圣衣、白银圣衣、十二黄金圣衣、海界鳞衣、冥衣及神圣衣等系列。装备部件可拆分为头盔、胸甲、护肩、护腕、腰甲、腿甲等。

系统包括损坏、修复、强化、觉醒、进化、幻化、收藏图鉴、圣衣箱展示、外观查看、着装演出与形态切换。幻化外观不覆盖当前装备属性。

## 6. 角色成长

等级与经验、攻击/防御/生命/速度属性、技能学习升级、技能觉醒、小宇宙培养、第七感与第八感、称号、时装、伙伴、宠物、坐骑、成就、收藏和个人圣域据点。

## 7. 剧情与任务

篇章规划：
- 银河战争篇
- 圣域十二宫篇
- 海皇篇
- 冥王篇
- 天界篇
- 原创终极篇

任务类型：主线、职业专属、角色支线、隐藏剧情、NPC 剧情、Boss 剧情和原创补充剧情。

任务闭环：NPC 触发 → 接受任务 → 地图导航 → 探索/即时战斗 → 剧情对话 → 完成目标 → 发放奖励 → 解锁后续内容。

普通任务默认屏内对话；重要主线与关键 Boss 使用独立剧情界面，支持角色展示、镜头切换、表情动作以及可选配音。两种对话模式共用任务状态。

## 8. 地图与资源包

地点规划包括五老峰、日本城户宅邸、银河竞技场等。地图支持区域探索、NPC、怪物、副本、任务标记、传送点和隐藏区域。

基础安装包含启动游戏所需的核心程序、基础角色和基础地图。后续资源按篇章分包，可查看容量、导入、安装和删除可选资源包；删除资源不得误删存档。已安装资源必须完全离线可用。

## 9. 离线存档与商城

- 多个本地角色与存档槽。
- 存档备份、恢复和手动导入/导出。
- 离线商城只使用游戏内货币。
- 不设置真实货币支付、在线充值、账号门槛或服务器依赖。
