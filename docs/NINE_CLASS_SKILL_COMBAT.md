# 九大职业技能战斗系统

## 职业阵营与原作归属规则

阵营以原作身份为准，不按技能风格、职业定位或装备外观推断：

- 天猛星：冥界阵营，哈迪斯麾下冥斗士；对应天猛星拉达曼迪斯，属于冥界三巨头。
- 天琴座：圣域阵营，雅典娜麾下白银圣斗士；对应天琴座奥路菲。奥路菲曾进入冥界并为恋人留下，不因此改变其圣斗士身份。
- 海燕：原作对应身份尚未核实。当前职业暂标记为“待核实（暂不归属）”，不擅自划入圣域、海界或冥界；在确认其具体原作人物/星座/鳞衣或圣衣来源前，不写入阵营战争与阵营声望关系。

后续所有职业、NPC、敌对单位、剧情任务、圣衣/鳞衣/冥衣与阵营声望，均使用明确的原作归属。角色出现立场变化时，记录剧情时间点与原因，不覆盖其原始身份。

## 已有技能内容

- 九大职业：天马座、天龙座、白鸟座、仙女座、凤凰座、海龙、天猛、天琴、海燕。
- 每职业 24 项技能目录，共 216 项（6 项基础技能 + 18 项进阶技能）。
- 每职业有独立普攻三段名称、核心技能、连招、奥义、职业被动与战斗资源主题。
- 进阶技能分三个专精分支，包含技能 ID、解锁等级、消耗、冷却、定位与说明。
- 技能学习、技能点、专精分支选择、四格主动技能栏、技能装备和技能树重置已有本地逻辑。
- HUD 已有四个可点击技能栏位，点击后调用玩家技能释放逻辑；角色界面可查看技能、学习并装备。

## 本次战斗效果扩展

`game/scripts/game.gd` 的统一技能效果处理增加了：
- 冻结、减速、灼烧、虚弱等敌方状态效果。
- 面向判定与范围技能判定。
- 牵引、击退、打断等控制反馈。
- 护盾/防御减伤、治疗恢复生命与小宇宙。
- 狂怒/增益/召唤类攻击强化。
- 闪避/替身无敌窗口和突进位移。
- 技能命中后显示影响目标数量或自身效果提示。

敌人现有状态机负责冻结、减速、灼烧持续伤害、虚弱攻击削弱；Boss 保留冻结抗性与蓄力霸体，避免被普通控制无限打断。

## 技能使用流程

1. 角色升级获得技能点。
2. 在角色界面打开当前职业技能图鉴。
3. 满足等级与技能点要求后学习技能。
4. 进阶技能需先选定对应专精分支。
5. 将已学习技能装备到四个主动技能栏。
6. 回到战斗场景点击技能栏，消耗小宇宙并进入独立冷却。
7. 技能根据职业、技能类型、范围与目标状态触发效果。

## 重要说明与验收边界

216 项是技能内容目录，不代表 216 项都拥有独立定制动画、独立粒子、独立音效或经过平衡的专属机制。当前已具备通用主动释放入口和按类型分派的程序化战斗效果；部分不同技能仍会复用通用伤害/状态模板。下一步需要逐职业逐技能验证释放条件、目标选择、伤害、冷却、能量、Boss 抗性和技能栏触控，并继续补充真正不同的技能机制、连段取消、骨骼动画、粒子与音效。

源码提交不等于 Godot 引擎或 Android 真机验收。本系统仍需 Godot 4.4 项目解析运行、APK 导出和魅族 21 Pro 测试。
