# 开发路线

## 阶段 0：仓库与技术选型（当前）

- [x] 建立独立 GitHub 仓库。
- [x] 写入核心设计与开发路线。
- [ ] 核对开发电脑 AMD 显卡型号、显存与驱动。
- [ ] 对比 Godot 4 与 Unreal Engine 5 的 Android 导出、3D 动作能力和电脑资源要求。
- [ ] 确定唯一主引擎与项目目录。

## 阶段 1：Android 可玩战斗原型

- [ ] 建立可导出的横屏 Android 工程。
- [ ] 玩家角色移动、镜头跟随、虚拟摇杆。
- [ ] 普攻、至少两个即时技能、闪避与目标锁定。
- [ ] 一个基础敌人和一个 Boss。
- [ ] 手机 HUD 初版与触控区域调校。
- [ ] 在目标手机上实机安装、运行和性能测试。

## 阶段 2：核心 RPG 系统

- [ ] 角色属性、经验、等级与技能成长。
- [ ] 装备、圣衣部件、强化与外观。
- [ ] 背包、掉落、游戏内货币和离线商城。
- [ ] 本地存档、多存档槽、备份/恢复。

## 阶段 3：任务、剧情与地图

- [ ] 任务状态机、NPC 对话与任务追踪。
- [ ] 屏内对话和独立剧情对话界面。
- [ ] 地图探索、导航、传送点和区域加载。
- [ ] 首个完整剧情篇章与 Boss 任务链。

## 阶段 4：内容扩展

- [ ] 九大职业与职业专属技能。
- [ ] 圣衣进化、神圣衣、收藏图鉴。
- [ ] 伙伴、宠物、坐骑、成就与个人据点。
- [ ] 其余剧情篇章与原创终极篇。

## 阶段 5：资源包、优化与 Windows

- [ ] 按篇章管理离线资源包。
- [ ] 资源校验、导入、安装、删除和容量统计。
- [ ] LOD、纹理压缩、按需加载和临时资源释放。
- [ ] Android 画质档位、帧率与热量测试。
- [ ] Windows 输入、界面和画质适配。

## 验收原则

每个阶段都必须有可运行结果和明确验收标准。优先保证核心战斗可玩，不以静态界面或演示视频代替游戏功能。
