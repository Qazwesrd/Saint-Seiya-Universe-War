# 开发路线（Android 手机 / Godot 4）

- [x] 选定 Godot 4 作为主引擎。
- [ ] 确认开发电脑 Vulkan 支持与 Godot 编辑器运行情况。
- [ ] 安装 Godot 4 稳定版及 Android 导出所需 SDK/JDK。
- [ ] 建立项目目录、输入映射、基础场景和资源规范。

## 验收原则

每个阶段都必须有可运行结果和明确验收标准。优先保证核心战斗可玩，不以静态界面或演示视频代替游戏功能。最终以 Android 真机安装、运行和完整离线游玩作为交付验收标准。
