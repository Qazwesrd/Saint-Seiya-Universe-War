# 第二阶段：核心 RPG 系统

## 目标
在 Android 离线单机战斗原型上建立可持续成长的角色数据层。

## 已加入的系统源码
- 九大职业基础属性、职业选择和初始装备数据。
- 角色等级、经验累计、升级循环与等级属性成长（上限 100）。
- 攻击、防御、生命、速度、小宇宙上限等战斗属性计算，装备和强化属性实时叠加。
- 背包物品数量、装备槽位（头部/胸部/手臂/腿部）、穿戴、替换与最高 10 级强化。
- 离线货币、商店购买、消耗品使用。
- 小宇宙培养等级与货币消耗。
- 三个本地存档槽、自动保存、独立备份与恢复。
- 数据版本字段，便于后续存档结构升级。

## 九大职业
天马座、天龙座、白鸟座、仙女座、凤凰座、海龙、天猛、天琴、海燕。职业数据集中维护，不擅自补写未经确认的原作背景。

## 经济与商城规则
- 货币仅在游戏内获得与消耗。
- 不接入真实货币支付、联网充值、账号服务器或付费墙。
- 商店购买校验商品、价格和余额；不能出现负余额。
- 消耗品与装备分开处理。

## 存档规则
- 存档写入 Godot user:// 私有目录。
- 3 个存档槽互相独立。
- 备份/恢复操作验证 JSON 类型和版本号。
- 不存储账号、网络凭据或在线服务数据。

## 本阶段验收
1. 九大职业列表完整且可选择。
2. 升级后等级、经验与属性正确变化。
3. 装备穿戴、替换、属性叠加正确。
4. 商城购买扣除游戏货币并加入背包。
5. 三个存档槽可独立保存/读取，备份可恢复。
6. 退出重启后数据仍存在。
7. Godot 4.4 编辑器解析通过，并在 Android 真机检查存档路径和触控交互。

## 当前限制
系统源码已提交，但在 Godot 编辑器和 Android 真机运行通过前，不标记为实测完成。模型、动画和圣衣外观仍需后续正式美术资源替换。
