# 技术决策记录

## 当前状态：主引擎尚未确定

本项目**仅开发 Android 手机版本**。不开发 Windows 电脑版，不安排桌面端或其他平台适配。最终选择前，重点比较：

| 项目 | Godot 4 | Unreal Engine 5 |
|---|---|---|
| 开源/授权 | MIT 开源 | 按 Epic 当前许可条款 |
| 编辑器资源占用 | 通常较轻 | 通常较高 |
| 3D 角色与动画生态 | 可实现，需更多整合 | 生态和现成工具较丰富 |
| Android 导出 | 支持，需配置 SDK/JDK | 支持，工具链与构建体量更重 |
| 本项目适配重点 | 轻量、移动端优先 | 高品质 3D、复杂动画与特效 |

## 决策条件

1. 唯一目标平台为 Android 横屏手机，首要测试机为魅族 21 Pro（Snapdragon 8 Gen 3、Adreno 750、16GB RAM）。
2. 开发电脑为 Windows 11、16GB RAM、AMD 显卡；具体型号与显存待确认。电脑配置仅用于开发，不代表要制作 Windows 游戏版本。
3. 先验证一个角色在手机上移动、普攻、释放技能、闪避和攻击 Boss。
4. 引擎必须能够稳定导出 Android 安装包，并适合长期维护大型 3D 手机游戏。
5. 不依赖云服务器或在线游戏服务。

## 初始技术方向

采用单机本地架构：游戏逻辑、任务数据、角色数据、资源管理与存档均在 Android 客户端运行。界面、输入和性能方案全部围绕手机触控与移动设备进行设计。

## 资源与性能原则

- 约 5GB 是首次安装内容的规划目标，不是要求生成一个 5GB 的单体 APK。
- 后续按篇章提供独立离线资源包，容量由用户设备剩余空间决定。
- 通过区域分块加载、LOD、纹理压缩、按需加载和及时释放控制运行时内存。
- 不将游戏总磁盘容量等同于运行时 RAM 占用。
- 优先测试触控响应、帧率稳定性、设备温度、耗电和长时间运行表现。
