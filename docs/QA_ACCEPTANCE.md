# Android 真机验收清单

此清单用于 Debug APK 成功导出后的最终手工验收。自动化检查通过不代表以下真机项目已经通过。

## 安装与启动
- [ ] APK 安装成功，应用可正常启动。
- [ ] 强制横屏；刘海/圆角安全区域内的按钮不被遮挡。
- [ ] 主菜单、存档管理、角色创建向导可正常打开和返回。
- [ ] 角色名称、九大初始职业选择正确；神明职业/天斗士不会被误列为初始职业。

## 存档与离线
- [ ] 飞行模式下启动、创建角色、战斗、保存、退出和重新读取均正常。
- [ ] 三个存档槽相互隔离；备份、恢复、删除和覆盖保护正常。
- [ ] 强制结束应用后重新启动，存档仍然存在。
- [ ] 无网络请求、登录依赖或真实货币支付入口。

## 触控与镜头
- [ ] 左右手布局切换后摇杆和技能按钮位置正确。
- [ ] 多点触控下可同时移动、转镜头和释放技能。
- [ ] 镜头距离、灵敏度和垂直反转设置生效。
- [ ] 所有按钮在不同分辨率/显示缩放下都能点击。

## 战斗与成长
- [ ] 普攻、三段连击、闪避、防御、技能和小宇宙爆发正常。
- [ ] 自定义连招保存、切换、删除和自动衔接正常。
- [ ] 领域、陷阱、追踪弹、召唤物命中和结束逻辑正常。
- [ ] 天斗士飞行、上升、俯冲及切换职业后的状态清理正常。
- [ ] 神明职业专属印记、支援效果和 Boss 抗性正常。
- [ ] 主要 Boss 蓄力预警、闪避窗口、恢复期和专属重击正常。

## 剧情与系统
- [ ] 七篇章剧情顺序、NPC 对话、任务目标和奖励正确。
- [ ] 篇章切换时环境主题正确。
- [ ] 每日 Boss 按本地固定时间刷新；离线设备时间可被修改，不能视作服务器防作弊。
- [ ] 自动拾取开关、地面掉落拾取、装备、背包、图鉴和任务追踪正常。

## 稳定性与性能
- [ ] 低/中/高画质、帧率、渲染比例、阴影和特效开关生效。
- [ ] 连续战斗至少30分钟，无崩溃、卡死、存档损坏或实体无限堆积。
- [ ] 记录平均帧率、发热、耗电和内存；检查后台恢复与来电/切换应用后的恢复。
- [ ] 记录所有问题的复现步骤、日志、截图和发生时的设置。
