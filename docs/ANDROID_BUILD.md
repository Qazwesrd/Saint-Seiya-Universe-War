# Android ARM64 一体化安装包

本项目最终采用**单个 APK 一体化交付**：游戏程序和所有已完成、已验收的离线游戏资源一起写入 Godot 导出的主资源包（`main.pck`），主资源包随 APK 安装。玩家只下载并安装一个 APK，不再另找章节数据包，也不依赖首次启动联网下载。

## 一体化交付规则

- Android 导出预设必须使用 `export_filter=all_resources`，不得排除正式游戏资源。
- 所有正式地图、角色模型、圣衣、动画、技能特效、音频、UI、剧情和章节数据都必须位于 Godot 导出资源范围内，并随 APK 的 `main.pck` 一并交付。
- 章节仍按内容目录和资源清单管理，但这是游戏内部组织方式，不是让玩家另外下载的文件。不能把 `planned` 状态的章节误报为已制作或已安装。
- 安装后首次启动执行内置资源清单/版本检查；资源缺失、版本不匹配或校验失败时明确报错，不允许静默进入缺资源状态。
- 正式包必须在完全断网、清除应用数据后的全新安装条件下验证；不能依赖开发机缓存、GitHub Artifact 或之前安装遗留文件。
- 构建报告分别记录 APK 文件大小、APK 内主资源包大小、安装后占用和安装所需临时空间。不得用空文件、重复文件或缓存凑容量。
- 若完整内容使单个 APK 超出 Android 安装/分发限制，必须先评估 Android 安装器与签名分发的真实限制，再调整为由同一个官方安装器自动部署其内置资源；不能退回要求玩家手动寻找、复制第二个数据包的方案。

## 目标容量（最终正式版）

- APK 安装文件目标：**3–4 GiB**。
- APK 内随包离线游戏内容目标：**15–20 GiB 或更大**，具体按真实完成并验收的资源统计；不得用无用数据填充。
- 安装后存储占用会因压缩、解压和文件系统开销而变化，必须单独实测并报告。
- 以上是正式版目标，不代表当前原型已经达到。当前 CI 产物仍是 Debug 测试包，不是正式完整游戏。

## 触发测试构建

1. 打开 GitHub 仓库：Qazwesrd/Saint-Seiya-Universe-War。
2. 进入 **Actions**。
3. 选择 **Android APK Export**。
4. 点击 **Run workflow**，选择默认分支并确认。
5. 等待工作流完成；成功后在本次运行页面的 Artifacts 中下载 **Saint-Seiya-Universe-War-Android-ARM64-debug**。

## 构建类型与验收边界

- 当前工作流导出 Debug APK，面向安装和功能测试，不是正式签名发布包。
- APK 仅针对 Android ARM64；导出成功不等于真机测试通过，也不等于最终 3–4 GiB / 15–20 GiB 容量已达标。
- 安装后需验证横屏、启动、角色创建、战斗触控、存档读写、章节资源完整性、完全断网启动和长时间运行。
- 正式发布前仍需确定正式签名密钥、版本号、应用图标、隐私与发行信息；不要把调试签名包当成正式发行包。
