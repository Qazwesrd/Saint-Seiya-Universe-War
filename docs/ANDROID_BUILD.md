# Android ARM64 安装包与国内网络自动下载

最终交付采用**一个 APK + 首次启动自动下载完整离线数据**。玩家只下载、安装 APK；游戏优先连接中国大陆可访问的 HTTPS CDN；国内主线路发生网络或 HTTP 错误时，自动切换到海外备用 CDN，下载并安装所有已发布章节数据。玩家不需要手动寻找、解压或复制数据包。VPN 不是游戏的必需条件。

## 玩家安装流程

1. 下载并安装一个 Android ARM64 APK。
2. 首次启动后，游戏自动检查版本、手机剩余空间和网络。
3. 游戏通过国内 CDN 自动下载已发布的章节资源包，显示总体进度、当前文件和下载状态。
4. 下载采用 HTTP Range 分段续传；网络中断或退出后保留已下载部分，下次继续。
5. 每个文件按 APK 内置的可信清单 SHA-256 校验；全部校验通过后才原子切换安装。
6. 所有资源安装完成后，游戏可以完全离线运行。以后更新只下载变更的资源包。

## 国内网络与服务器要求

- 主线路：CDN/对象存储部署在中国大陆可访问的网络环境，使用备案域名和有效 HTTPS 证书；服务商和域名备案由发行方完成。
- 备用线路：配置独立的海外 HTTPS CDN/对象存储，建议与主线路使用不同服务商或网络出口，避免单点故障。
- `cdn_base_urls` 按顺序填写主线路、备用线路；下载器逐请求尝试，网络失败、HTTP 错误或 Range 响应不正确时切换下一条线路。各线路必须提供相同版本、相同路径的资源文件，并使用相同 SHA-256 校验值。
- 国内玩家默认不需要 VPN；备用线路仅是自动容灾线路，不代表国内网络在任何地区都必然能访问海外服务器。
- 服务端必须支持 HTTP Range 请求，正确返回 206 Partial Content 和 Content-Range；资源服务器需正确配置访问策略。
- 资源包使用版本化路径；清单记录每个文件的相对路径、字节数和 SHA-256。APK 内固定清单文件的 SHA-256，防止下载站替换清单。
- 不将大型资源托管在 GitHub Release、境外网盘或需要 VPN 的站点作为正式下载源。
- 实际能否在不同运营商、地区和时段稳定访问，必须在中国大陆移动网络、联通、电信及 Wi-Fi 环境实测；海外备用线路也需实测。不能只凭线路名称承诺全网无阻。
- 目前仓库尚未配置真实 CDN 域名、资源包清单哈希和已发布数据包，因此自动下载功能在配置完成前保持关闭；不能使用虚构域名或假下载链接。

## 下载器能力

- HTTPS 请求；4 MiB 分段下载。
- 支持 HTTP Range 断点续传。
- 文件大小和 SHA-256 双重校验。
- 暂存目录下载，验证通过后再切换安装；更新失败保留旧版本。
- 空间不足时停止并提示所需容量。
- 下载中断保留 .part 文件；重试时继续下载。
- 安装完成后可断网启动，不在游戏过程中依赖 CDN。

## 最终容量目标

- APK：约 **3–4 GiB**。
- 首次启动下载的完整离线数据：约 **15–20 GiB 或更大**，按实际制作并验收的资源统计。
- 安装后占用还包括解压、索引和存档空间，必须单独实测报告；不允许用重复文件、空文件或缓存凑容量。
- 这些是正式版目标，不代表当前原型已达到。当前 CI 导出仍是 Debug 测试包。

## 构建与验收

1. Godot Android ARM64 导出 Debug APK，供安装测试。
2. 构建报告记录 APK 大小、资源包大小、下载总量和 SHA-256。
3. 在中国大陆网络环境验证下载、续传、校验、安装和更新。
4. 清除应用数据后重新安装，确认首次下载成功；关闭网络后验证所有已安装章节可玩。
5. 验证目标魅族 21 Pro 的存储空间、安装时间、温度、内存和帧率。

正式发行前还需配置正式签名、真实 CDN/对象存储、备案域名、证书、资源清单哈希和发行版本号。
