# 阶段四：职业技能、圣衣成长与本地 GM 管理

## 九大职业技能
- 天马座：天马流星拳 → 天马彗星拳
- 天龙座：庐山升龙霸 → 庐山亢龙霸
- 白鸟座：钻石星尘拳 → 曙光女神之宽恕
- 仙女座：星云锁链 → 星云风暴
- 凤凰座：凤翼天翔 → 凤凰幻魔拳
- 海龙：黄金三角次元 → 海龙怒涛
- 天猛：天猛重击 → 钢铁冲击
- 天琴：弦乐幻境 → 死亡交响曲
- 海燕：海燕疾风 → 旋流突袭

已实现职业技能名称、能量消耗、冷却、伤害倍率和颜色配置；技能等级 1—10，可在角色面板消耗星币升级，伤害随等级提升。施放职业技能后开启 1.6 秒连招窗口，窗口内可按独立连招按钮施展职业连招并消耗额外小宇宙。

当前连招已具备数值、窗口和输入调用流程；九职业独立动作、命中判定差异、技能树分支和完整动画仍待开发。

## 圣衣成长
- 阶段：青铜、白银、黄金、海界鳞衣、冥衣、神圣衣、主神圣衣。
- 部件：头盔、胸甲、护腕、腰甲、腿甲。
- 每个部件记录耐久和强化等级；玩家每五次受击损耗一个部件耐久点。
- 耐久状态会影响圣衣提供的攻击、防御和生命加成。
- 可消耗星币修复全部部件、逐件强化；黄金、神圣、主神圣衣可觉醒。
- 当前阶段支持解锁和切换圣衣，圣衣数值已接入 RPG 战斗属性。

圣衣模型、真实部件外观、着装/变身动画、光效、圣衣箱图鉴和不同职业专属圣衣模型仍待开发。

## 本地 GM 管理
GM 面板可执行：
- 增加星币、经验和设置等级。
- 恢复角色生命与小宇宙。
- 发放全部已定义物品。
- 重置当前任务（需要二次确认）。
- 解锁全部圣衣阶段、切换圣衣。
- 修复全部圣衣部件、强化指定部件、觉醒当前圣衣。
- 设置当前职业技能等级。

GM 是本机离线调试工具，不连接服务器、不创建账号、不涉及真实货币。操作日志保存在本次运行内存中，重启后不保留。
