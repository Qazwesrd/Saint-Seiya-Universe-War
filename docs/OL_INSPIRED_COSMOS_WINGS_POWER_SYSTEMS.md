# 《圣斗士星矢OL》参考方向：角色成长与战力系统扩展

## 设计定位与边界

本项目以《圣斗士星矢OL》的 MMORPG 成长体验作为玩法参考，采用横屏 3D 即时动作、单机离线结构。参考其系统层次与操作体验，不复制原游戏客户端、代码、模型、贴图、动作、音乐、UI 文件或其他未获授权资源。所有正式资源必须自制或取得明确授权。

以下是目标设计规格，不代表相关系统已经全部实现。每个系统需经过源码、游戏内表现和 Android 真机验收后才能标记完成。

## 一、小宇宙系统（核心成长系统）

小宇宙不只是一个战斗能量条，而是角色长期培养、战斗爆发和圣斗士身份成长的核心系统。

### 1. 小宇宙能量与爆发
- 战斗中通过攻击、受击、完美闪避、格挡和职业特性积累小宇宙能量。
- 能量达到阈值后可主动燃烧小宇宙，进入限时爆发状态。
- 爆发状态影响技能表现、攻击节奏、抗打断能力或特定职业效果；数值必须受职业和 Boss 抗性平衡约束。
- 设置能量消耗、恢复速度、爆发持续时间、冷却和 UI 反馈；离开战斗后按规则缓慢恢复或清空，不能无限维持。

### 2. 感官与觉醒阶段
- 成长路线包括五感突破、第六感、第七感、第八感及更高阶的剧情限定境界。
- 每一阶段有明确等级/任务/试炼门槛、专属演出、被动效果和技能解锁。
- 第七感是重要战斗转折；第八感属于高阶剧情与挑战内容，不作为开局默认能力。
- 神职业使用独立神格成长分支，不能简单把凡人等级数值放大。

### 3. 星座与小宇宙盘
- 设置可配置的小宇宙星盘/星图节点，包含攻击、防御、生命、速度、暴击、能量恢复、控制抗性等分支。
- 节点通过游戏内材料培养；提供重置预览和确认，显示战力变化。
- 星盘应有职业推荐方案与自由搭配，限制同类增益叠加上限，避免单一最优解碾压。

### 4. 小宇宙装备/组件
- 设计独立组件槽位和套装组合，组件有品质、主属性、副属性、套装效果与成长等级。
- 组件名称、图标、属性、掉落来源和套装效果均可在图鉴查询。
- 不以随机词条制造付费抽卡；所有获取均通过离线任务、副本、Boss、制作或游戏内商店。

## 二、战力评分系统

- 角色面板显示综合战力，并可展开查看来源：等级基础、职业成长、小宇宙、圣衣/装备、技能、翅膀、称号、伙伴/宠物、坐骑及其他系统。
- 战力是对角色构筑强度的参考评分，不等同于真实 PvE 伤害，也不能作为唯一胜负标准。
- 每次培养/装备/技能变化后即时重算；显示提升或下降的具体来源。
- 避免重复统计同一属性；百分比、固定值、临时 Buff 和战斗状态分开计算。
- Boss 设计应有机制与抗性，不能只靠战力数值检查阻挡玩家。

## 三、战力翅膀系统

### 1. 翅膀定位
- 翅膀是独立外观与成长装备，不与圣衣、神衣、天衣混为一类。
- 提供背部挂点、角色动作适配、待机/移动/战斗/觉醒状态动画，以及低/中/高画质特效。
- 可选择隐藏翅膀、只显示外观或显示当前装备外观；外观幻化不改变属性。

### 2. 翅膀成长
- 设立阶位、星级、强化、进阶、觉醒、外观图鉴和材料收集。
- 每阶拥有独立轮廓、羽片/能量结构、材质、粒子效果与进阶演出；不得仅靠改色或放大模型充数。
- 翅膀属性以有限的攻击、防御、生命、速度或小宇宙加成为主，设定总加成上限并纳入战力计算。
- 翅膀材料来自篇章任务、精英/Boss、副本挑战、探索与制作；所有系统完全离线，不接入充值或联网抽奖。

### 3. 翅膀主题系列
- 可规划星辰之翼、圣光之翼、暗影之翼、凤凰之翼、海皇之翼、冥界之翼、天界之翼、神域之翼等原创外观系列。
- 每个系列需有清晰设计语言和来源剧情；名称及造型标注原创/授权状态，不能误称为原作正式装备。

## 四、与《圣斗士星矢OL》体验相呼应的成长系统

### 1. 圣衣收集与养成
- 圣衣/鳞衣/冥衣/神斗衣/天衣/神明神衣等分类独立建档。
- 支持部件穿戴、修复、强化、觉醒、进化、幻化、收藏图鉴、套装共鸣和着装演出。
- 圣衣外观与职业模型骨骼挂点适配；神圣衣与神衣必须是不同装备类别。

### 2. 技能与职业培养
- 职业技能树分主动、被动、连招、奥义/觉醒分支。
- 技能升级消耗可通过游戏内玩法获得的材料；提供技能预览、重置与构筑保存。
- 职业间有坦克/输出/控制/辅助等战斗定位，但单机内容必须允许单人通关，伙伴可弥补队伍功能。

### 3. 称号、时装与外观收藏
- 称号来自剧情、探索、Boss、成就和挑战，部分提供少量属性，纯外观称号不增加战力。
- 时装与圣衣幻化分离，提供染色/部件显隐/外观收藏；外观不覆盖装备属性。
- 图鉴记录来源、获取条件、版本与完成度。

### 4. 伙伴、宠物、坐骑
- 伙伴可提供辅助战斗、协同技能或剧情互动；宠物提供轻量辅助和收藏；坐骑负责地面移动与区域探索。
- 各自具备独立模型、跟随/召唤行为、动作、碰撞与 UI 图标。
- 伙伴与宠物的战斗能力有上限，不能自动代替玩家操作或让 Boss 战失去机制。

### 5. 副本、试炼与离线活动
- 章节副本、精英挑战、Boss 讨伐、星座试炼、小宇宙试炼、圣衣修复/收集任务、翅膀材料挑战。
- 日常/周常采用本地时间与离线重置规则，不依赖服务器；避免错过奖励惩罚和强制在线。
- 难度提供剧情、普通、困难、挑战档，奖励明确可查。

### 6. 圣域与社交体验的单机化
- 个人圣域据点、训练场、装备展示区、收藏陈列室、NPC 好感/伙伴剧情。
- 公会/组队等在线依赖功能不伪装成真实在线多人；可改造成 NPC 守护组织、离线伙伴编队和单机挑战榜。
- 所有保存数据本地可备份、恢复，不需要账号或云端。

## 五、Android 横屏体验与性能要求

- 适配魅族 21 Pro 横屏分辨率与安全区域；技能栏、虚拟摇杆、战力/小宇宙面板不遮挡主要战斗视野。
- 小宇宙、翅膀、觉醒、Boss 大招特效需有移动端 LOD、粒子数量、透明层和阴影预算。
- 翅膀骨骼/羽片动画、披风、头发和圣衣部件需控制骨骼数量与材质批次。
- 提供低/中/高画质与特效开关；优先稳定帧率、温度和内存，目标设备实测后再确定默认画质。
- 完成断网启动、存档、章节切换、战斗、系统培养与资源包读取测试。

## 六、当前状态标注

当前仓库已有部分小宇宙能量/培养数据、爆发入口、圣衣成长、职业技能、伙伴/宠物/坐骑基础数据等代码，但不代表以上完整系统已完成。翅膀完整模型、阶位进阶、动作挂点、UI、战力分项计算、小宇宙星盘/组件玩法等需逐项实现和验证。

不得将设计文档、数据目录、占位图形或静态 UI 标记为完整功能。验收必须证明：系统可操作、数据能保存、数值计算正确、战斗中生效、界面显示正确、Android 离线运行通过。
