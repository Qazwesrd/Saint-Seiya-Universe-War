# 即时战斗 AI 与反馈模块

## 本轮内容

- `game/scripts/enemy.gd` 改为显式状态机：追击、蓄力预警、攻击结算、后摇、受击硬直、死亡。
- 攻击蓄力期间显示地面红色环形预警；结算时重新检查距离，玩家走出范围即可躲避。
- 普通敌人与 Boss 使用不同的攻击距离、伤害、攻击间隔和蓄力时间。
- Boss 生命低于 50% 时进入第二阶段，提升移动速度和伤害并改变发光颜色。
- 敌人受击时产生短暂硬直和击退；Boss 的击退幅度较低。
- 玩家新增敌人击退响应，闪避无敌状态下不触发击退。

## 当前边界

- 仍使用程序化胶囊占位模型和环形预警，不代表已接入正式骨骼动画或完整特效。
- 目前攻击是近距离范围结算，不是骨骼武器命中盒；技能仍沿用现有范围伤害接口。
- 受击硬直、Boss 阶段、预警时长和击退数值属于首轮可玩参数，后续需要在手机端调校。
- 本轮只完成源码提交与静态文本核验；未在 Godot 4.4 编辑器解析，未导出 APK，未进行魅族 21 Pro 真机测试。
