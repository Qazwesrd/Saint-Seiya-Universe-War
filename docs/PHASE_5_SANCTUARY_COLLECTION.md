# 阶段五：个人圣域、伙伴跟随与收藏奖励

## 已提交源码

- 独立个人圣域区域：竞技场 HUD 入口可进入圣域，也可返回进入前的位置。
- 圣域成长：等级上限 10；修炼场、小宇宙泉、圣衣工坊各有 10 级，消耗星币升级。
- 离线收益：设施按等级累计经验与星币，离线累计上限 24 小时；收益需玩家手动领取。
- 伙伴/宠物：已装备的伙伴和宠物以程序化占位模型跟随玩家；收藏变更后刷新跟随对象。
- 坐骑：HUD 可切换骑乘/下马，骑乘时移动速度增加；当前为状态和特效占位，不是正式坐骑模型。
- 成就：初次胜利、训练有素、Boss 挑战者、百战勇士支持一次性领取经验与星币奖励，领取状态进入本地角色存档。

## 数据与存档

圣域数据保存在 RPGState.profile.sanctuary，包含等级、设施等级、上次领取时间和访问次数。成就领取记录保存在 RPGState.profile.collection_state.claimed_achievements。所有功能均为本地离线逻辑，不连接服务器。

## 当前边界

- 圣域建筑为程序化几何占位，尚无正式建筑美术、可摆放装饰、完整 NPC 和交互任务。
- 伙伴/宠物跟随为基础位置追随，占位球体，不含正式角色模型、骨骼动画、碰撞或战斗 AI。
- 坐骑暂为骑乘状态、速度增益和光环提示，不含坐骑模型、骑乘姿态、动画与地形适配。
- 仍需使用 Godot 4.4 编辑器解析和运行，并在 Android 设备上检查触控、性能、存档及离线时间计算。
