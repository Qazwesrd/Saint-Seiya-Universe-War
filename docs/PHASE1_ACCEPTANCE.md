# 第一阶段验收：Android 3D 即时战斗原型

## 已提交的原型内容
- Godot 4 项目配置与主场景。
- 程序生成的竞技场、地面碰撞、环境光和灯光。
- 天马座占位角色、第三人称跟随镜头、移动和转向。
- 普通攻击、天马流星拳、小宇宙爆发、闪避和目标锁定逻辑。
- 普通敌人与 Boss 的追击、近战攻击、受击和死亡逻辑。
- 手机 HUD：角色生命/小宇宙条、目标数量、按玩家与敌人位置绘制的实时小地图、Boss 生命条、虚拟摇杆、普攻/技能/闪避/锁定/小宇宙按钮及技能冷却显示。

## 真正验收必须完成的步骤
1. 使用 Godot 4 稳定版打开 game/project.godot，检查脚本解析与场景加载。
2. 运行主场景，验证移动、镜头、普攻、技能、闪避、锁定、敌人 AI 和 Boss。
3. 配置 Android SDK/JDK 与 Godot Android 导出模板。
4. 配置 Android 横屏导出预设并生成 APK。
5. 在魅族 21 Pro 安装 APK，验证触控、画面比例、帧率、温度和长时间运行。
6. 根据实测结果修复问题，再标记阶段验收通过。

**当前状态：战斗原型源码、Android ARM64 导出预设和自动化检查工作流已提交；尚未取得 Godot 编辑器/CI 实际解析结果，也未完成 APK 构建或魅族 21 Pro 真机验证。未执行的测试不会标记为通过。**

## 操作说明
- 左下虚拟摇杆：移动。
- 右下普攻：近距离扇形攻击。
- 流星拳技能：消耗小宇宙，对前方范围造成伤害。
- 小宇宙：消耗能量，对周围敌人造成范围伤害。
- 闪避：快速移动并短暂无敌。
- 锁定：锁定最近敌人。
- 目标：击败两个普通敌人与一个 Boss。
