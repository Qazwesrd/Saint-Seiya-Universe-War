# 圣斗士：宇宙之战

一款以圣斗士题材为灵感的离线 3D 即时动作 RPG，**仅开发 Android 手机版本**，采用横屏操作。

> 当前阶段：Android 战斗原型源码已提交，尚待 Godot 编辑器解析、实际运行、APK 构建和魅族 21 Pro 真机验收。

## 核心目标

- **即时动作战斗**：自由移动、普攻、技能、连招、闪避、格挡、锁定目标与 Boss 战；不采用回合制。
- **完全离线单机**：无需账号、服务器或联网验证；存档保存在本机。
- **Android 手机优先且为唯一目标平台**：以魅族 21 Pro（Snapdragon 8 Gen 3、Adreno 750、16GB RAM）作为首要测试设备。
- **手机体验优先**：围绕触控操作、横屏 HUD、续航、发热、内存和安装/资源管理进行设计。
- **分章节资源包**：基础安装内容与银河战争、圣域十二宫、海皇、冥王、天界及原创篇章资源分开管理。

## 手机操作布局

横屏 HUD：左上角色头像与状态，其下任务追踪与对话；右上小地图、地图左侧商城入口；左下虚拟摇杆；屏幕中下方技能；右下普通攻击。闪避、锁定和小宇宙按钮应避免遮挡核心操作。

## 九职业差异化技能

- 每个职业拥有独立的三段普攻招式名称、主动技能、专属连招和小宇宙终结技。

## 开发原则

1. 只针对 Android 手机开发，不安排 Windows 电脑版或其他平台适配。
2. 先做可运行、可操作的战斗切片，再逐步扩展内容。
3. 主引擎已确定为 Godot 4，继续完善 Android 导出与真机验证。
4. 资源按需加载，控制运行时内存、发热和耗电。
5. 不将 APK 单文件大小与游戏总资源容量混为一谈；约 5GB 是初始安装内容的规划目标，后续资源包容量按设备空间管理。
6. 原作角色、剧情、美术、音乐及游戏资源用于公开发行或商业用途前，必须确认授权；未获授权时采用原创替代内容。

## 九职业技能体系扩展

每个职业现有六项分级技能资料、专属职业被动和职业资源主题，技能图鉴按解锁等级展示。天马偏高速斗志爆发、天龙偏防御守护、白鸟偏冰冻控场、仙女偏锁链牵制与守护、凤凰偏火焰持续伤害与复苏、海龙偏次元突袭、天猛偏重击与抗压、天琴偏音律辅助、海燕偏高速机动。当前主动战斗仍沿用已有技能按钮与命中系统；冻结/灼烧/治疗/格挡/召唤等完整效果、技能树加点与专属动画仍需后续开发，不将技能资料目录误称为全部可实战技能。


## 九职业 216 项技能库

每个职业拥有 24 项技能：6 项核心技能与 18 项进阶技能。进阶技能划分为三个专精分支，每个分支 6 项，并配置技能 ID、解锁等级、消耗、冷却、定位和描述。九职业共 216 项技能目录。当前这是技能数据与图鉴目录扩充，不代表 216 项技能都已接入可释放战斗逻辑；完整效果、技能树加点、动画与特效仍在开发路线中。


### 九职业技能战斗效果扩展

主动技能现在会触发职业差异化状态：冻结、减速、灼烧、虚弱、牵引，以及职业自身的临时攻击/减伤增益。Boss 对冻结有抗性，避免控制链永久锁死。当前为程序化战斗效果，尚不代表正式动作动画或全部技能目录均可释放。


### 九职业技能树与主动技能栏

技能树支持角色升级获得技能点、技能学习、专精分支锁定、技能树重置、四格主动技能装备与释放。技能按职业等级、技能点、专精和小宇宙消耗限制使用；不同技能类型触发相应程序化战斗效果。旧版本存档会补齐技能字段，不主动删除既有进度。

天界篇与全系列装备图鉴设计范围见 `docs/GAME_DESIGN.md` 和 `docs/ROADMAP.md`。当前为设计与路线登记，尚未代表全部角色、装备模型、技能和剧情均已实现。
